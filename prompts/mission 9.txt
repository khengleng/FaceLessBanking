You are building the FaceLessBanking Admin / Ops Web Portal.

Use these frontend standards consistently across all pages unless explicitly overridden:

Stack:
- React + TypeScript
- React Router
- TanStack Query for data fetching/caching
- React Hook Form + Zod for forms/validation
- a single component library/design system consistently across the app
- reusable API client layer with typed request/response models

UI rules:
- all pages must use shared layout, table, filter, status badge, modal, and empty/error/loading components
- destructive actions require confirmation modal
- all mutations must show pending, success, and error states

- all detail pages must handle partial/missing data safely
- no duplicated table/filter implementations unless necessary

- use protected routes

- hide unauthorized navigation items
- never expose admin controls without explicit role checks

Data rules:
- use query hooks for reads
- use mutation hooks for writes

- handle backend error envelopes consistently

Testing rules:
- add tests for route access, loading/error/empty states, successful render, and critical actions
- do not skip tests for protected routes and approval/rejection flows

Deliverables:
- production-oriented, modular, reusable code
- no placeholder-only page shells unless explicitly requested
