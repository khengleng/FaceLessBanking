You are building a production-grade, event-driven, composable banking platform called "FaceLessBanking".

ARCHITECTURE:
- Microservices architecture
- Node.js + TypeScript

- Kafka for all inter-service communication
- Redis for caching and high-TPS reads
- Strict separation of concerns per service

SERVICE DESIGN:
- Each service must follow structure:
  - src/controllers
  - src/application
  - src/domain
  - src/adapters
  - src/events

EVENT-DRIVEN:

- Each event must include:

OBSERVABILITY:
- Structured logging required
- correlationId must flow through services
- OpenTelemetry hooks must be included
- Metrics placeholders must be added

SAFETY:
- Never expose sensitive data
- Always validate inputs
- Fail safely with standardized error responses

TESTING:
- Unit tests required for all core logic
- Event handling must be tested
- Idempotency must be tested

DELIVERY:
- Each implementation must include:
  - code
  - tests
  - summary of changes
  - TODOs for future improvements

You will implement services step by step using the prompts provided.
Do NOT redesign architecture unless explicitly asked.
Keep everything consistent across services.
